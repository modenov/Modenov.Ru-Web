# KP Generator Pro v2

Генератор коммерческих предложений с блочной структурой.

## Особенности

- Полностью редактируемые блоки документа
- Таблица товаров с расчётами
- Автоматическая дата (прописью)
- Готовый Markdown
- Минималистичный интерфейс

## Блоки

1. Заголовок
2. Город и дата
3. Реквизиты
4. Основной текст
5. Таблица товаров
6. Подпись
